              01.
              zomboid-server Hybrid Cloud Gateway
            

            Vagrant + FRP + Azure
          

          

            A dedicated server infrastructure bypassing CGNAT/firewalls without port-forwarding by tunneling local Docker containers through an Azure FRP reverse proxy.
          

          
[Client (Internet)] ──► [Azure FRPS Gateway: UDP 16261/16262]
                              │ (Secure FRP Reverse Tunnel)
                              ▼
┌────────────────────────────────────────────────────────┐
│ Local Host: Windows Virtualization                      │
│   Vagrant VM (Ubuntu Focal64)                          │
│     Docker Compose:                                    │
│       ├── FRP Client (frpc) ◄──► Azure FRPS            │
│       └── Project Zomboid (LinuxGSM)                   │
└────────────────────────────────────────────────────────┘
